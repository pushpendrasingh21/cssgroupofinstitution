# CSS Group of Institutions — Angular Website

Professional responsive Angular website using the supplied CSS Group logo as a transparent PNG.

## Included
- Home, About, Courses, Admissions, Contact and Enquiry pages
- Angular Router navigation
- Reactive enquiry form with validation
- Enquiry data saved to browser localStorage
- Responsive mobile navigation
- Professional navy/gold/tricolour visual theme
- Logo at `public/assets/logo.png`

## Run locally
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local URL shown by Angular CLI.

## Build for hosting
Run `npm run build`. The production files will be generated under `dist/css-group/` (path may vary slightly with Angular CLI output settings).

## Important
The enquiry page is currently frontend-only and stores submissions in the visitor's browser. For real admissions enquiries, connect the submit handler to your backend/API, email service, Google Sheets, CRM, or database.
